# EDIO Sample
This directory contains a [pre-built ROM](./edio.z64) using [libdragon](https://github.com/DragonMinded/libdragon/) - from January 2026.

## Features
This [pre-built ROM](./edio.z64) contains the following features supported by the Everdrive 64 Pro:

- Debug `printf` over USB
- Copying file data into memory
- Copying memory data into file
- USB data transmission
- USB data reception
- File system access
- RTC access
- Getting path to the currently running ROM
- Cartridge configuration
- Reading device ID
- Basic internet access demo over USB
